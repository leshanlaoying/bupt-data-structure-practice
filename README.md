# BUPT 国际学院数据结构练习题库

📚 **BUPT International School · Data Structures Practice**

本项目整理了北京邮电大学国际学院数据结构课程的相关练习题及个人题解，旨在帮助同学们巩固数据结构知识，提高算法设计与编程能力。

题库持续更新，主要采用 **C 语言** 实现。

🔗 网站地址：https://leshanlaoying.github.io/bupt-data-structure-practice/

## 📖 题库内容

目前包含以下六个专题：

- 线性结构（Linear Structures）
- 树（Trees）
- 图（Graphs）
- 排序（Sorting）
- 散列（Hashing）
- KMP 字符串匹配（KMP Algorithm）

每道题目包含题目描述、输入输出格式、测试样例及 C 语言题解。
